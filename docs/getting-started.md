# Getting Started

Welcome! This guide will walk you through the steps to get your project set up with MkDocs and publish it to Confluence.

## Prerequisites

Before you begin, ensure you have:

- Python 3.8 or higher
- Git installed
- An Atlassian Confluence account
- An API token from your Atlassian account
- A Confluence space and page to publish under

## Project Setup

1. **Clone the Repository**  
   Clone the custom MkDocs + Confluence plugin repository:

   ```bash
   git clone https://github.com/denizzsarierr/mkdocs-with-confluence.git
   cd mkdocs-with-confluence
   ```
