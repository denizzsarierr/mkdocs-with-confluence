# Usage Guide

This guide explains how to use MkDocs with the custom Confluence plugin to write, preview, and publish your documentation.

---

## Writing Documentation

All documentation is written in **Markdown** (`.md`) files located in the `docs/` folder.

### Example:

```markdown
# Introduction

Welcome to the documentation site!

## Features

- Easy publishing to Confluence
- Markdown-based documentation
- Simple configuration
```
